RF4 – Développement web

M. IQDOUR Radouane 34 heures Semestre 2

Description du module

Le module "Technologies et Développement Web" a pour objectif de permettre aux stagiaires d'utiliser les technologies les plus récentes pour concevoir et développer des sites et des applications Web statiques et dynamiques pour des fins éducatives.

Compétences visées

Au terme de ce module, le stagiaire est capable d'utiliser les technologies les plus récentes pour concevoir et développer des sites et des applications Web statiques et dynamiques pour des fins éducatives.

Objectifs du module

  • Découvrir les notions fondamentales liées au développement Web
  • Concevoir et développer des sites web statiques interactives
  • Développer des applications Web dynamiques en utilisant un langage de programmation web

Prérequis

  • Bases de données
  • Programmation structurée
  • Connaissances de base en internet

Contenu du module

1. INTRODUCTION AU DÉVELOPPEMENT WEB

  • Définition et origines du web
  • Différence entre "Internet" et "Web"
  • Fonctionnement du Web
  • Notion de client Web et serveur Web
  • Communication entre client et serveur

2. DÉVELOPPEMENT DE SITES WEB STATIQUES

  • HTML : Présentation, structuration d'une page web, principales balises, création de pages, intégration de ressources
  • CSS : Présentation, mise en forme des composants HTML, classes et identifiants, optimisation des feuilles de style
  • JavaScript : Présentation, bases du langage, manipulation d'une page JavaScript

3. DÉVELOPPEMENT DE SITES WEB DYNAMIQUES

  • Différence entre page web statique et dynamique
  • Le modèle client/serveur
  • PHP : Présentation, historique, fonctionnalités, syntaxe
  • Variables, structures de contrôle, fonctions en PHP
  • Variables tableaux en PHP
  • Manipulation de fichiers en PHP
  • Gestion des erreurs en PHP
  • Gestion des données des formulaires
  • Gestion de la sécurité pour les applications web
